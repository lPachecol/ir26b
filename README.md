# Recuperación de Información - ICCD753

Repositorio personal para la asignatura de Recuperación de Información de la Escuela Politécnica Nacional.

Aquí se alojan las soluciones a las actividades prácticas y notebooks desarrollados a lo largo del curso. El objetivo de este repositorio es mantener un historial reproducible del trabajo realizado y construir funciones o módulos de código que se puedan reutilizar en las siguientes actividades de la materia.

## Temáticas aplicadas

Basado en la estructura del curso, en este repositorio se irán implementando componentes sobre:

- Modelos clásicos (Recuperación booleana, Espacio Vectorial, TF-IDF, BM25).
- Evaluación de sistemas de recuperación (Precision, Recall, F1-score, MAP, NDCG).
- Construcción de índices invertidos y representación de documentos.
- Búsqueda vectorial y Dense Retrieval.
- Sistemas RAG (Retrieval-Augmented Generation).

---

El código está desarrollado en Python y las prácticas están diseñadas para ejecutarse en entornos como Google Colab o Jupyter Notebook.
